# ML и оценка качества

## Данные

data/query_dataset.jsonl содержит 300 русских тикетов: 12 тем по 25 примеров,
эталонный ответ, обязательные/запрещённые факты, ожидаемый документ, действие,
канал и устройство. 100 исходных формулировок взяты из CC0 Banking Requests,
остальные сгенерированы детерминированными шаблонами. Разбиение фиксировано:
180 train, 60 development, 60 test.

Train обучает модель, development выбирает порог 0.22, test используется один
раз для отчёта. Тексты test не индексируются в Qdrant, иначе retrieval-метрики
были бы утечкой.

## Подход

На горячем пути используется символьный TF-IDF (3–5-граммы) и Logistic
Regression. Это быстрый интерпретируемый baseline без LLM-вызова. При наличии
явного денежного сигнала классификатор безопасно поднимает лучшую high-risk тему
из собственного Top-3. Затем отдельный policy gate проверяет итоговую тему.

Автозакрываются только четыре узких FAQ-темы: способы оплаты, цена, скачивание
чека и отключение продления. Остальные получают черновик, но требуют оператора.
Низкая уверенность также всегда означает human_review.

## Метрики

- классификация: accuracy, macro-F1, Top-3 accuracy;
- безопасность: high-risk recall и число false negative;
- policy: action accuracy и auto-close precision;
- retrieval: Hit@1, Recall@3, MRR;
- ответ: покрытие обязательных фактов, доля запрещённых фактов, token-F1;
- производительность: p50/p95 классификации.

Критические пороги: high-risk recall 1.0, false negative 0, auto-close
precision не ниже 0.98, p95 меньше 500 мс; для live hybrid retrieval дополнительно
Recall@3 не ниже 0.90 и forbidden fact rate 0.

Текущий test: accuracy 0.75, macro-F1 0.745, Top-3 0.933, high-risk recall
1.0, auto-close precision 1.0. Невысокая общая accuracy приемлема только для
PoC благодаря консервативному human-in-the-loop; перед production нужны реальные
тикеты, калибровка вероятностей и анализ confusion matrix по каналам.

LLM-as-a-judge не используется: он медленный, платный и может разделять ошибки
с оцениваемой моделью. Проверки ответа основаны на размеченных фактах и токенах.
